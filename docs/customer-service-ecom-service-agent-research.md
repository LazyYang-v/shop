## 架构与 README 核实

README 将项目定位为从 Prompt、结构化响应和会话管理，逐步演进到 ReAct/工具、MCP、RAG、多 Agent、Memory、Skill 和评估；把 Guardrails、人机协作及 Observability 列为“生产篇”规划。[README 路线图](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/README.md#L94-L120) 固定版本树中实际存在前述 ReAct、MCP、RAG、Multi-Agent、Memory、Skill 和 Evaluation 模块及相应测试；没有独立的 Guardrails、Human-in-the-Loop/工单、Observability 实现目录。故生产篇是规划，不能视作已经交付的能力。[README 架构树](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/README.md#L128-L229) · [固定版本树](https://github.com/HuaiNan54321/ecom-service-agent/tree/b0f55585ad7ed827fd74c3d0f228914adc72bbc1)

核心是 Python CLI。`EcomAgent` 使用 OpenAI Python 客户端构造 ReAct 循环，收集模型工具调用、执行并把结果放回对话，然后另行提取 Pydantic 结构化响应；`ToolManager` 可连接 MCP，并按 `allowed_tools` 筛选工具。[ReAct 循环](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/chat.py#L14-L55) · [工具循环和结构化提取](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/chat.py#L110-L220) · [工具管理与过滤](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/manager.py#L14-L95) README 的单 Agent/Multi-Agent 切换、会话、技能、MCP 和离线评估入口在相应源码与配置中可找到；README 所说“五分钟启动”是说明文字，本次没有运行项目或验证耗时。[Quick Start](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/README.md#L16-L68) · [配置](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/config/settings.py#L4-L53)

仓库也有独立 FastMCP Streamable HTTP 服务，监听 loopback 地址并暴露订单、商品、物流、退款和知识搜索工具；代码本身没有买家登录/会话鉴权层。[MCP 服务](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/mcp_server/server.py#L1-L64) README 的 RAG 声明由实现支持：Markdown 知识文档经 embedding 和可切换的 NumPy/Chroma 后端检索；NumPy 后端把向量写入 JSON 并全量计算余弦相似度，retriever 检查索引与 embedding 模型是否一致。[检索器](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/rag/retriever.py#L20-L53) · [NumPy 后端](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/rag/backends/numpy_backend.py#L24-L103) README 对 Memory、Skill、评估的模块描述也有对应源码：skill loader 按需读入说明文件，memory 从对话提取事实并以 JSON 跨会话保存，评估器组合工具过程指标、回答结果指标与可选 LLM judge。[Skill loader](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/skills/loader.py#L69-L159) · [长期记忆存储](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/memory/long_term.py#L30-L83) · [评估器](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/evaluation/evaluator.py#L56-L156)

## 关键边界与实现风险

仓库明确使用 Mock 数据：订单、商品、物流都来自进程内字典，商品未命中时还会随机生成一条模拟商品。[Mock 数据](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/mock_data.py#L1-L81) 退款工具只按模拟订单状态返回“已取消/已提交/预计退款”等成功话术，没有连接真实订单或支付系统，也没有在这些分支中更新订单状态。[模拟退款逻辑](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/refund.py#L1-L27) 因而这些演示适合理解工具调用教学流程，不构成可迁移到真实买家订单的业务实现。

政策文档是仓库内直接写定的退换货规则；RAG 工具只按相似度返回片段与分数，没有商城批准记录、版本、生效区间、权威登记或撤回后再次核验机制。[示例退换货政策](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/rag/knowledge/退换货政策.md#L1-L51) · [知识检索工具](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/knowledge.py#L61-L114) 这与本地客服的政策设计有实质差别：本地仅允许明确标注的合成登记，索引只定位候选文档，答复正文和引用回到有版本/生效期的登记核验；真实 WeKnora 与真实商城政策并未在当前作品集启用。[backend/src/shop_api/customer_service_policy.py:1–7](../backend/src/shop_api/customer_service_policy.py#L1-L7) · [同文件:76–108](../backend/src/shop_api/customer_service_policy.py#L76-L108) · [同文件:374–431](../backend/src/shop_api/customer_service_policy.py#L374-L431) · [docs/customer-service-portfolio-release.md:5–18](customer-service-portfolio-release.md#L5-L18)

README 标题中的“企业级”定位不应作为安全或生产证明。[README 标题](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/README.md#L1) 订单工具按订单号访问全局 Mock 字典；MCP 服务公开订单号/商品/物流查询及退款函数，没有当前商城会话身份、订单买家归属、显式订单选择、确认凭据或事务证据。[订单工具](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/order.py#L1-L10) · [MCP 暴露的工具](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/mcp_server/server.py#L22-L64) 本地 ADR 则要求权限来自服务端登录会话、订单只能查当前买家本人、模型不得执行取消；取消必须经一次性确认，并以同事务的执行证据核实。[docs/adr/0001-customer-service-authority-boundary.md:3–13](adr/0001-customer-service-authority-boundary.md#L3-L13)

其他差异也影响直接移植：上游工具管理器在 MCP 连接异常时退回本地工具，适合教学可用性演示，但接入真实业务时会改变工具来源且需明确失败语义；其本地 MCP adapter 未强制核对远端服务器身份。[MCP fallback](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/tools/manager.py#L41-L68) 长期记忆默认 `user_id="default"`，并以文件形式保存抽取事实，代码未呈现商城身份映射或本地数据保留治理。[默认身份配置](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/config/settings.py#L33-L41) · [记忆文件路径与写入](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/agent/memory/long_term.py#L30-L83) · [MCP 客户端连接流程](https://github.com/HuaiNan54321/ecom-service-agent/blob/b0f55585ad7ed827fd74c3d0f228914adc72bbc1/app/mcp_client/client.py#L17-L59)
