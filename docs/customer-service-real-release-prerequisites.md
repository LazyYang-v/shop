### D. 账号适用的数据处理与保留契约

提供方材料应明确覆盖实际 API 服务与账号；政策名称/版本、官方来源、适用地区、协议或书面确认及适用依据：〈待填〉。不能用网页产品开关或通用公开政策替代账号适用证据。

| 数据/责任范围 | 必须填写的契约与证据 |
|---|---|
| 模型输入、输出及人工访问 | 〈待填：是否训练/优化/人工审核、退出机制、API/账号覆盖及生效证明；无退出时的明确批准结论〉 |
| 内容、请求日志及滥用监测 | 〈待填：各类别期限、起算点、安全/法律例外、地域与次处理者〉 |
| 供应商备份与删除 | 〈待填：备份期限、删除入口、在线/备份完成时限、例外及可取得的删除证明〉 |
| WeKnora 全链路 | 〈待填：app/代理/解析器/索引/对象/缓存/日志/宿主机及外部快照的保存、备份和删除责任〉 |
| 商城真实数据处理 | 〈待填：数据流/字段清单、处理依据与用户披露、聊天/证据/账本/日志期限、清理及备份恢复方案〉 |

零保留、训练退出和删除完成期限均不得推定；回复时限不等于删除时限。演示的无运行期备份与本地保留参数不自动覆盖真实范围；未知项须解决并明确批准处理条件后才能放行。

## 二、工程后续可实施且必须验证的工作

下列工作按材料中的确切资源、操作和调用预算执行；本清单不表示已完成或已获执行授权。每项证据记录 UTC 时间、源码/镜像版本、脱敏配置摘要、输入/预期/实际、失败与复测、复现方式及责任人。

| 项目 | 执行与通过条件 | 待填证据 |
|---|---|---|
| E1 权威登记及真实适配 | 实现真实来源加载与 KB+文档映射；正文哈希、不可变版本、UTC 区间、状态、条件和来源均校验；未知映射/索引指令无回答资格；拒绝重叠发布 | 〈待验：实现、审批包与 API 记录〉 |
| E2 最小权限与撤销 | 新端点重新核验协议/Schema、仅检索白名单、批准 KB 正向和越范围负向；运行身份写入/ask/Wiki 拒绝；测旧凭据撤销、新凭据及在途行为 | 〈待验：专用端点脱敏矩阵〉 |
| E3 发布、撤回与清理 | 用批准专用资源验证发布/更新；商城立即停止引用撤回政策并在交付前复核；异步清理后检查三种检索模式及已列明的直接读取/缓存等路径；备份按契约处理，记录未覆盖范围 | 〈待验：版本链、撤回时间、清理结果〉 |
| E4 独立政策问题集 | 题集审阅人、冻结哈希、期望答案/依据和质量阈值均待确认；独立于开发回归，覆盖真实主题/条件、无匹配、冲突、失效、无关高分和注入；盲测逐题记录召回与引用正确性 | 〈待填阈值；待验题集与逐题结果〉 |
| E5 故障、限流与取消传播 | 实测检索 5 秒/步骤 10 秒、并发 4、每轮 1 次无重试；覆盖 401、工具错误、partial_failures、断连、超限/共享计数失效及恢复；错误不冒充无政策，订单独立路径继续受权限保护 | 〈待验：请求轨迹及故障恢复矩阵〉 |
| E6 依赖结束与槽位 | 分别测客户端返回、本地取消/槽释放、远端实际结束及在途撤销；检索未结束仍占槽。模型沿用已批准 90 秒本地 TTL，记录迟到结算，不能据此声称远端终止或始终最多两在途 | 〈待验：时间线、计数及迟到结果〉 |
| E7 六工具真实提供方 | 按 C 表验证真实 API 的 JSON/工具参数/结果往返、额外字段拒绝、组合调用、失败降级、usage/原子预算及额度耗尽；按冻结门面裁剪字段，不把确认权交给模型 | 〈待验：六行实绩、去重总数/金额〉 |
| E8 数据最小化与保留 | 核对真实数据流及自由文本处理；合成哨兵检查模型请求、日志和各存储出口；实测到期清理、失败告警、备份删除与隔离恢复；本地清理不作为供应商删除证据 | 〈待验：字段/存储清单、契约、清理恢复记录〉 |
| E9 发布及回退 | 对准确候选镜像完成 API 与桌面/移动浏览器验收、权限竞争/取消幂等及证据一致性；独立恢复并测 RTO/RPO，验证回退与能力关闭；历史演示结果不能代替当前候选 | 〈待验：候选版本、部署/恢复/回退证据〉 |

检索零命中和有限观察窗口不证明全索引、缓存或备份删除完成；无法覆盖的路径必须列明并按契约处置。
