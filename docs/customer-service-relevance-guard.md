# Issue #1 确定性相关性保护与验证

日期：2026-10-22。状态：**方案确定，离线参考验证通过；未接入商城，不宣称生产验证通过**。用户授权确定并验证主题及条件明确、无法确定则拒绝回答的方案。本轮没有新增网络请求、知识库写入、令牌轮换或收费模型调用。

## 决定

采用“受控完整问句规则→结构化范围→检索候选ID映射→政策资格→规范正文引用”的保守流程。hybrid分数仅排序，不能授予回答资格。此决定替代此前最低hybrid分数阈值作为相关性保护的方案；生产阈值仍为空，不把缺阈值偷偷当成阈值0。

这是当前合成政策集上的有限覆盖方案，不是通用自然语言理解器。没有匹配、匹配多条、出现未覆盖条件时，返回needs_clarification，不输出政策结论。对于已识别的库存、订单等诉求，应由已批准的确定性分流进入相应业务路径；本参考仅拒绝将其当政策，不实现商品或订单查询。明确不支持退款时沿既有范围说明当前无法办理，不以澄清暗示可以办理。

## 保护契约

1. 每个受支持范围显式登记entity、topic、conditions及版本资格；不能只使用任意scope_key字符串或由模型自报主题。测试范围为ALPHA/包装颜色、BETA/标签形状、GAMMA/标记字母。
2. 仅做NFKC、首尾空白和单个句末问号规范化；实体必须完整匹配，不用子串命中。参考语法全句匹配，不先删除未知子句后再匹配关键词。语句含退款、库存、多个实体、第二个问题、额外地区/会员/金额/日期或指令时，未覆盖即不进入该政策范围。
3. 条件槽位必须由可信业务事实或用户明确提供且可核实的输入满足；缺失或未知不得当作false/全地区/普通会员。参考数据无附加条件，所有非空条件均保守拒绝；它不证明真实地区、金额或会员规则已实现。
4. 检索问题使用用户原始含义，限定批准库，top5。候选按可信KB+文档ID关联登记，实体、主题和条件与已解析范围完全一致才有资格；未知映射拒绝。分数再高也不能跨主题回答。
5. 按商城服务端时间检查active及[from,to)，登记冲突即停止，撤回/未来版不引用。上下文只取已登记规范正文，不取摘要或候选自由文本作权威来源。语法匹配不允许覆盖身份和确认规则。
6. 本轮参考不生成自然语言推断，只返回合格政策别名。生产答复应使用批准的主题模板呈现规范事实，比较问题可以列出当前有效事实，不擅自推导未登记条件或承诺；交付前仍须复核引用资格。
7. 不能解析：needs_clarification，说明“暂无法确定适用的政策主题或条件，请补充具体问题”，无政策引用。不声称没有政策。已解析但候选全失效/未知/不适用：policy_unavailable；有效范围内没有足够依据也不借分数补答。本次参考的空候选统一保守unavailable，未实现产品完整no_match分类。

## 可复现验证

参考脚本：[policy-relevance-offline.py](policy-relevance-offline.py)。仅标准库，无商城、数据库、网络或凭据依赖。它与正常产品实现分开，避免把#1可行性验证等同于实施#4。

```bash
# 自包含：40项离线检查
python3 -I docs/policy-relevance-offline.py

# 若本地真实检索证据仍在：额外回放12题，不重新调用WeKnora
python3 -I docs/policy-relevance-offline.py \
  --evidence /tmp/shop-policy-live-search-evidence.json
```

实际结果：**40/40离线检查，12/12真实候选记录回放检查通过**。本地汇总/tmp/shop-policy-relevance-results.json；脚本及预期已落仓库，可重跑自包含部分。第一次40项运行39通过：包装语法过宽接受不完整“ALPHA包装颜色”；收紧为完整问句后重跑全部通过。不是零缺陷的独立首次评测。

## 与既有条件的关系及剩余缺口

- 用户要求的“先明确主题和条件，无法确定拒答”在此参考中落实；最低分数阈值被确定性资格门替代。原top5及最多3引用、有效期登记、不可变版本原则不变。
- 暂不Rerank仍不等于已证明它不必要。有限表达可由规则保护；开放问法、同义覆盖、政策规模增长仍需独立真实问题集。超出覆盖时牺牲回答率以避免无据作答，不自动转模型猜主题。
- 生产政策及其条件尚未提供，登记条件之间的重叠关系未验证；需为每个真实主题审核规则、模板及条件来源，禁止直接把合成实体规则上线。
- 完整商城路径、共享限流、并发发布和引用交付一致性仍未验证。独立参考不能关闭这些项。
- 专用令牌撤销未完成；失效瞬间WeKnora原始检索零旧命中的强要求仍未满足。

#1继续OPEN。可行性结论为“在显式有限主题及表达覆盖内，确定性资格检查可拒绝本次高分无关反例”；不能写成“客服相关性保护已生产实现”。
