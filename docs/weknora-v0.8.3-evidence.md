| MCP 发布与传输 | 内置工作区发布端点使用 **Streamable HTTP、stateless**，路径 `/mcp/<endpoint_id>`，挂载 POST/GET/DELETE；不能把独立 Python 包的 stdio/SSE 配置套用到此端点。Python MCP server 官方已标记弃用。见 [发布说明](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/mcp-server/README.md#L3-L7)、[路由](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/router/routes_mcp_endpoint.go#L31-L48)、[传输实现](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/server.go#L108-L121)。 | 未验证端点发布、代理转发、initialize/协议协商及真实客户端兼容性。 |
| 工具 Schema 与白名单 | 内置目录有 12 个工具：`list_knowledge_bases/search_knowledge/grep_chunks/list_documents/read_document/ask/wiki_search/wiki_read_page/wiki_index/add_document/update_document/delete_document`。白名单同时控制 tools/list 可见性与 tools/call 执行，不能靠猜名字绕过。默认排除三个 ingest 写工具，但默认包含 `ask`；`ask` 会创建会话和消息，并运行配置的 agent，自身明确标记非只读。见 [目录/默认值/能力映射](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/types/mcp_endpoint_tools.go)、[双重防护](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/server.go#L146-L181)、[ask schema](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_ask.go#L26-L42)。 | 尚未取得部署实际 tools/list；不能冻结已启用白名单。客服所需白名单应显式选定，不能默认为默认全部工具。 |
| 知识库/令牌范围与撤销 | 专用端点 Bearer token 只从 Authorization 读取，查询参数 token 不接受；数据库存 SHA-256 hash。端点固定 tenant、工具列表和 KB 列表，生成 API-key 风格 scope；请求指定的 KB 必须在可访问集合内，并重新经权限解析。**KB 列表为空表示整个工作区范围，非空权限集合应显式配置。** rotate 替换 hash；enabled=false 阻断新请求，删除端点也有管理 API。模型未定义 expires_at，Authenticate 未执行 token 到期检查。见 [认证](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/middleware/mcp_endpoint_auth.go#L17-L89)、[范围模型](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/types/mcp_endpoint.go#L21-L48)、[KB 解析](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/scope.go#L15-L142)、[旋转及认证](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/mcp_endpoint.go#L211-L288)。 | 未验证跨 KB/跨租户拒绝、旧 token 失效、禁用/删除后拒绝；也未证明撤销能中断在途调用。缺少获准 KB 与专用最小权限令牌，仍阻塞。 |
| 政策版本/有效期过滤 | `search_knowledge` 外部参数只有 query、mode、limit、knowledge_base_ids；**无 policy_version、effective_from/to、as_of 或通用 metadata filter**。内部 SearchParams 有文档/标签范围，但也没有政策时间字段；不能因支持 custom metadata 就声称具备政策强制过滤。手工文档编辑存在内部版本自增，也不等于检索按政策版本筛选。见 [外部 schema](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_retrieve.go#L43-L57)、[SearchParams](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/types/search.go#L253-L279)、[内部版本](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledge_create.go#L1046-L1054)。 | 此 MCP schema 无法直接满足该项。按版本隔离 KB、导入时只发布有效政策、返回后校验并拒绝失效来源等均仅为候选补偿，**未经验证、未获批准，不能作为验收通过依据**；仅对 top-k 后过滤也可能漏召回有效政策。 |
| 结果元数据/来源 | 工具成功返回 text，并在有 Data 时返回 structuredContent。搜索行含 knowledge_id、knowledge_base_id、knowledge_title、knowledge_metadata、match_type、match_snippet、score、source_query、query_type；普通文档有 chunk_id/chunk_index，FAQ 使用 faq_id/index。没有统一强制的政策版本、生效区间、公开来源 URL/页码字段；自由 metadata 需业务建立约束。见 [结果封装](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/server.go#L224-L248)、[结果字段](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/agent/tools/search_knowledge.go#L1098-L1136)。 | 未证明实际政策可由文档/分块 ID 稳定映射到版本、有效期和业务来源；来源不能映射时应维持阻塞。 |
| 更新、删除与旧条目残留 | MCP `update_document` 只编辑由文本创建的 Markdown，后台异步清旧索引并重新分块/向量化；添加成功也不等于可检索，响应提示 parse_status=completed 后才可检索。delete_document 调用 DeleteKnowledge 后返回 deleted=true；服务先标 deleting，删除索引、分块、图关系与文档，Wiki 清理含 best-effort 处理及撤回任务。因此不能据成功回包承诺所有检索路径/Wiki 无残留。见 [写工具](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_ingest.go#L28-L175)、[手工更新](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledge_create.go#L1000-L1093)、[删除流程](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledge_delete.go#L475-L643)、[Wiki 清理边界](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledge_delete.go#L180-L203)。 | 未执行更新/删除；旧关键词、语义检索、读取文档、Wiki 的残留窗口及失败恢复均待获准隔离数据验证。 |
| 混合检索与 Rerank | search_knowledge 默认 hybrid，也支持 semantic/keyword；实际 KB 的索引能力可能导致模式降级，embedding 失败时 hybrid 可退到 keyword，返回附 mode fallback / partial_failures。混合融合实现为归一化加权 RRF。**关键：内置 MCP 创建 SearchKnowledgeTool 时 rerankModel 参数传 nil；该工具仅在 rerankModel != nil 时重排，因此此 MCP search_knowledge 路径没有启用模型 Rerank。** REST HybridSearchWithRerank 是另一路径，不能等同。见 [MCP 工具构造](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_retrieve.go#L175-L194)、[重排条件](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/agent/tools/search_knowledge.go#L269-L283)、[降级](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/agent/tools/search_knowledge.go#L645-L724)、[RRF](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledgebase_search_fusion.go#L47-L83)、[REST 重排实现](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/application/service/knowledgebase_search_rerank.go#L59-L105)。 | 未验证部署 KB 的向量/关键词索引、权重、阈值、模型配置；若要求客服检索必须 Rerank，现有 MCP search_knowledge 契约有缺口。ask 的 agent 流程也不能替代原始检索契约证据。 |
| 超时 | ask 明确 4 分钟 context deadline，完成事件另有 15 秒等待常量；search_knowledge 的 MCP handler/guard 没有定义统一每调用 deadline，沿用 request context 和下游实现。见 [ask 超时](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_ask.go#L19-L24)、[deadline 使用](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_ask.go#L211-L217)、[搜索执行](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/tools_retrieve.go#L175-L194)。 | 未验证反向代理、客户端、模型/检索后端及总请求超时；4 分钟为源码值，并非客服批准 SLA。 |
| 限流与错误 | 工具调用按 endpoint ID 限流，源码默认 60 次/分钟；并非已批准业务值，也不代表并发上限。Redis 限流不可用时回退进程内 map，多实例下不能假定全局仍同一预算。超限返回 MCP tool error 文本 `rate limit exceeded for this endpoint, retry shortly`，该 guard 并非 HTTP 429/Retry-After 契约。认证层 HTTP JSON：缺失/错误 token 401、禁用/工作区失活 403、认证/工作区不可用 500；工具白名单/参数/服务错误是 MCP isError 路径，部分搜索失败可能是成功结果附 partial_failures。见 [guard](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/mcpserver/server.go#L161-L181)、[默认值](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/types/mcp_endpoint.go#L54-L56)、[本地回退](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/ratelimit/limiter.go#L65-L92)、[认证错误](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/middleware/mcp_endpoint_auth.go#L25-L57)、[部分失败附加](https://github.com/Tencent/WeKnora/blob/3e22822c1d2397be730c458c7539d0eb8c113a24/internal/agent/tools/search_knowledge.go#L330-L341)。 | 未验证实际配置、HTTP/MCP wire error、重试、取消传播、共享限流与并发；不应以高量请求试探限流。 |

## 供 issue 采用的结论

本次完成官方证据层核对，**未完成真实平台行为验收，也不冻结任何未批准参数**。当前接入仍应阻塞于：专用端点与最小权限 token、指定知识库范围及隔离/撤销证据、来源与政策版本/有效期的强制映射、版本过滤补偿的实际验证、更新删除无残留证据，以及 Rerank 是否为硬性要求及如何补足。

后续经授权的低量验证至少需保存脱敏的 initialize、tools/list、正常检索与越权拒绝、旧 token 撤销、来源映射、隔离文档更新/删除后多路径检索证据。模型提供方、编排、实例/并发上限、业务超时/限流、数据上限、保留期限及清理周期仍为未决项；本报告没有把源码默认值或候选补偿视为已批准运行契约。
